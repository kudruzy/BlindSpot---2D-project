# BlindSpot!

A 2D top-down survival exploration game built in Unity 6.

## About the Game
Navigate through maze environments while avoiding enemies using limited visibility and echolocation mechanics. Reach the green exit door to win!

## How to Play
1. Launch the scene in Unity.
2. Click **START** on the main menu.
3. Use the arrow keys / WASD to navigate toward the green exit door before the zombies catch you.

## Built With
* Unity 6
* C#
* TextMeshPro
